LOL 皮肤决策助手 0.1.0 · 便携版

【安装】
1. 把整个文件夹解压到非系统目录（例如 D:\Tools\LOL皮肤决策助手）。
2. 不要放进 C:\Program Files，避免没有写权限。
3. 不需要安装；删除整个文件夹即卸载。

【首次使用】
1. 先启动英雄联盟客户端（WeGame 或桌面快捷方式），登录到大厅。
2. 双击 LOL皮肤决策助手.exe；UAC 弹窗点“是”。
3. 看到召唤师名、英雄数、皮肤数即连接成功。
4. 未连接：点右上角刷新，并确认客户端已经登录。
5. 如果 Windows SmartScreen 拦截：点“更多信息”→“仍要运行”（程序未签名，不是病毒）。

【数据与隐私】
- 所有数据来自本机客户端的只读接口，不上传。
- 方案和缓存在本文件夹的 userdata\ 里，可随文件夹一起拷走。
- 不会修改客户端文件，也不会代付。

【系统要求】
- Windows 10 / 11 x64
- 英雄联盟国服客户端，已登录
- 无需安装 Node.js / Python
