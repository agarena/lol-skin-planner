# 逐屏测试用例（TEST）

> 版本：v0.1　｜　基准：`docs/SPEC.md` v0.1　｜　应用版本：0.1.0
>
> 原则：**按界面黑盒测试，不读代码判断行为**。每条用例只写「怎么点、应该看到什么」。
> 结果列留空，执行时填 `PASS / FAIL / BLOCKED`，FAIL 必须附截图或错误文案。

## 0. 使用说明

### 0.1 环境标记

| 标记 | 含义 | 准备方式 |
|---|---|---|
| **M** | mock 可测 | 打开 `http://127.0.0.1:5199/?mock=1`（或打包页 `?mock=1`） |
| **R** | 必须真实客户端 | 启动英雄联盟并登录大厅，管理员身份启动本工具 |
| **E** | 需要构造异常 | 断网、关客户端、改文件、旧分享码等，步骤里写明 |

### 0.2 执行前检查

- [ ] 记录应用版本、Windows 版本、屏幕分辨率与缩放比例。
- [ ] mock 环境确认地址栏含 `mock=1`，顶栏数值为 168 英雄 / 2008 皮肤量级。
- [ ] 真实环境确认顶栏绿点、召唤师名可显示、英雄数为 173 量级。
- [ ] 每次 FAIL 记录：用例 ID、实际现象、截图、控制台报错（如有）。

### 0.3 建议执行顺序

`GL → SC-01 → SC-02 → SC-03 → SC-04 → SC-05 → SC-06 → SC-07 → D`
先跑 M，再跑 R；E 类最后集中构造。
